1. Que se passe-t-il quand vous écrivez quelque chose à un modèle de langage ? Suivons une courte phrase à travers la machine.

  2. Tout commence par du texte : votre prompt. Le modèle ne voit jamais votre intention, seulement ces caractères.

  3. D’abord, le texte est découpé en tokens. Ce sont des morceaux de texte courants : souvent un mot entier, parfois seulement une partie.

  4. Chaque token est remplacé par son numéro dans le vocabulaire. À partir d’ici, votre prompt n’est plus qu’une suite de nombres.

  5. À chaque numéro correspond une liste de nombres, un vecteur. Il place le token comme un point dans un espace où les mots semblables sont proches les uns des autres.

  6. Les vecteurs traversent le réseau de neurones, un long empilement de couches. Chaque couche les réécrit un peu.

  7. En chemin, chaque token se retourne vers les tokens qui le précèdent et vers lui-même, et y prend ce dont il a besoin. C’est l’attention.

  8. À la fin, chaque token du vocabulaire reçoit une probabilité : quelles chances a-t-il de venir ensuite ? Ce qui est évalué, c’est ce qui est probable, pas ce qui est vrai.

  9. Puis vient une loterie. Un token à 45 % détient 45 billets sur 100. Le plus souvent, c’est un token probable qui gagne, parfois un token inattendu.

  10. Le token tiré est ajouté au texte, et tout recommence. C’est ainsi que la réponse s’écrit : un token à la fois.

  11. Au fond, ce n’est rien de plus : le texte devient des nombres, les nombres traversent le réseau, un token est tiré. Et l’on recommence.
