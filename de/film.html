1. Was passiert, wenn Sie einem Sprachmodell etwas schreiben? Folgen wir einem kurzen Satz durch die Maschine.

  2. Am Anfang steht Text: Ihr Prompt. Das Modell sieht nie Ihre Absicht, nur diese Zeichen.

  3. Zuerst wird der Text in Tokens zerlegt. Das sind häufige Textstücke: oft ein ganzes Wort, manchmal nur ein Teil davon.

  4. Jedes Token wird durch seine Nummer im Vokabular ersetzt. Von hier an ist Ihr Prompt nur noch eine Folge von Zahlen.

  5. Zu jeder Nummer gehört eine Liste von Zahlen, ein Vektor. Er setzt das Token als Punkt in einen Raum, in dem ähnliche Wörter nah beieinander liegen.

  6. Die Vektoren wandern durch das neuronale Netz, einen langen Stapel von Schichten. Jede Schicht schreibt sie ein wenig um.

  7. Dabei blickt jedes Token auf die Tokens vor ihm und auf sich selbst zurück und holt sich, was es braucht. Das ist die Attention.

  8. Am Ende erhält jedes Token des Vokabulars eine Wahrscheinlichkeit: Wie wahrscheinlich kommt es als Nächstes? Bewertet wird, was wahrscheinlich ist, nicht, was wahr ist.

  9. Dann wird gelost. Ein Token mit 45 % bekommt 45 von 100 Losen. Meist gewinnt ein wahrscheinliches Token, manchmal ein überraschendes.

  10. Das gezogene Token wird an den Text gehängt, und alles läuft noch einmal ab. So entsteht die Antwort: Token für Token.

  11. Mehr ist es im Kern nicht: Text wird zu Zahlen, die Zahlen gehen durchs Netz, ein Token wird gezogen. Und dann von vorn.
